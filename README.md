# ألعاب اللغة العربية التفاعلية – أ. ميار غانم | مدرسة دار المستقبل الخاصة

مشروع ألعاب تعليمية تفاعلية لمنهج «لغتي الجميلة» (الفصل الدراسي الأول) للصفين الخامس والسادس.

- **22 درسًا** (8 للصف الخامس + 14 للصف السادس)، ولكل درس صفحة مستقلة بها 5 ألعاب × 20 سؤالًا (100 سؤال لكل درس):
  اختيار من متعدد – الفقاعات المتساقطة – التنشين والاصطياد – صح أم خطأ – تحدي العباقرة.
- إرسال النتيجة عبر واتساب: يكتب الطالب اسمه، ثم يفتح واتساب برسالة النتيجة جاهزة ويختار محادثة المعلمة بنفسه (لا يوجد رقم هاتف في المشروع).

## هيكل الملفات
```
index.html              الصفحة الرئيسية (اختيار الصف)
assets/logo.jpg         شعار مدرسة دار المستقبل الخاصة
grade5/index.html       دروس الصف الخامس
grade6/index.html       دروس الصف السادس
gradeN/mX-...html       صفحة كل درس (mX = رقم المحور)
```

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات** هذا المجلد كما هي (index.html في جذر المستودع).
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
3. بعد دقيقة سيعمل الموقع على الرابط: `https://USERNAME.github.io/REPO/`
